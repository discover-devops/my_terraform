# Terraform Masterclass One Shot

## Course Overview

In this masterclass, we will learn Terraform from first principles. Instead of starting with syntax, we will first understand why Infrastructure as Code became one of the most important technologies in modern cloud engineering. By the end of this course, you will understand how Terraform works internally, how it communicates with cloud providers, and how to provision your first AWS infrastructure using Terraform.
